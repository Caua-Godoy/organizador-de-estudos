# Changelog

## [1.0.0] - 2025-06-01

### Adicionado
- comando `add` para cadastrar tarefa com titulo, materia e prazo
- comando `list` para listar tarefas pendentes
- comando `all` para listar todas as tarefas incluindo concluidas
- comando `done` para marcar tarefa como concluida
- comando `remove` para deletar uma tarefa
- persistencia em arquivo JSON local
- testes automatizados com pytest
- lint com ruff
- pipeline de CI com GitHub Actions
